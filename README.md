# Summarize YouTube Words Spoken

> [!WARNING]
> YouTube will block your IP if to rapidly used

## Installation

Please clone this repository and install the requirements.txt like so:

```
pip3 install -r requirements.txt
```


## Usage

``` sh
python3 . -c 10 -r 3 -v eIUqw3_YcCI
```

will output a list of words spoken that have more then 10 characters and are repeated at least 3 times.
